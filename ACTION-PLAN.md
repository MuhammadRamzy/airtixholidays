# AirTixHolidays SEO Action Plan

Based on the static SEO audit, here are the prioritized fixes sorted by impact and ease of implementation.

## 🔴 High Priority (Immediate Fixes)

### 1. Optimize Hero Image (`airplane-window.png`)
*   **Impact:** 🔴 **Critical** (Severely harms Core Web Vitals LCP & INP on mobile)
*   **Action:** 
    1. Compress `public/airplane-window.png` (currently ~1.46MB).
    2. Convert to a modern format like `.webp` or `.avif`.
    3. Ensure the `next/image` component using this image has the `priority` attribute set to true if it is loaded above the fold.

### 2. Fix Absolute Canonical Configuration
*   **Impact:** 🔴 **Critical** (Will cause duplicate content issues if subpages are added)
*   **Action:** 
    1. Open `src/app/layout.tsx`.
    2. Change `alternates: { canonical: "https://airtixholiday.com" }` to `alternates: { canonical: "/" }` or allow Next.js to auto-resolve it using the `metadataBase`.

### 3. Refactor JSON-LD Schema Location
*   **Impact:** ⚠️ **Warning** (Potential for duplicate schema warnings)
*   **Action:** 
    1. Move the hardcoded `TravelAgency` JSON-LD `<script>` tag from `src/app/layout.tsx` into `src/app/page.tsx`.
    2. This ensures the organization schema only fires on the homepage and gives room to add distinct schemas (e.g., `Service`, `Product`) on individual subpages.

### 4. Implement Dynamic XML Sitemap
*   **Impact:** ⚠️ **Warning** (Limits indexing of future content)
*   **Action:** 
    1. Refactor `src/app/sitemap.ts` to dynamically fetch all available routes or CMS slugs instead of hardcoding the `baseUrl`.
