## Detailed Findings

### 1. Technical SEO & Indexability
*   **Finding:** Hardcoded Absolute Canonical URL
    *   **Evidence:** `src/app/layout.tsx` lines 73-75: `alternates: { canonical: "https://airtixholiday.com" }`
    *   **Impact:** 🔴 **Critical** for scale. Setting an absolute URL in the root layout means every future nested page (e.g., `/about`) will tell Google its canonical URL is the homepage.
    *   **Fix:** Use relative paths (e.g., `canonical: "/"`) since `metadataBase` is already defined, or generate metadata dynamically per page.
*   **Finding:** Static XML Sitemap
    *   **Evidence:** `src/app/sitemap.ts` returns a single, static route.
    *   **Impact:** ⚠️ **Warning**. As new pages are added, they won't automatically be discovered by search engines.
    *   **Fix:** Convert `sitemap.ts` to dynamically map through your route directory or CMS content.
*   **Finding:** Permissive `robots.txt`
    *   **Evidence:** `src/app/robots.ts` allows `*`.
    *   **Impact:** ℹ️ **Info**. Currently allows all bots. Consider whether you want to restrict aggressive AI crawlers (e.g., `Bytespider`, `CCBot`) to save server bandwidth.

### 2. Performance & Core Web Vitals
*   **Finding:** Unoptimized Hero Image
    *   **Evidence:** `/public/airplane-window.png` is ~1.46 MB.
    *   **Impact:** 🔴 **Critical**. This will severely penalize your Largest Contentful Paint (LCP) and Interaction to Next Paint (INP) on mobile devices.
    *   **Fix:** Compress the image and convert it to `.webp` or `.avif`. Use Next.js `<Image />` component with `priority` if it's above the fold.

### 3. Schema & Structured Data
*   **Finding:** Hardcoded Root Schema
    *   **Evidence:** `src/app/layout.tsx` contains a static `<script type="application/ld+json">` injecting `TravelAgency` schema across the entire app.
    *   **Impact:** ⚠️ **Warning**. If this app gains subpages, the same organization schema will be duplicated on every single page.
    *   **Fix:** Move the JSON-LD script out of the root `layout.tsx` and place it strictly in `src/app/page.tsx` (the homepage). Let nested pages have their own specific schema (e.g., `Service` or `Product`).

### 4. AI Search Readiness (GEO)
*   **Finding:** Proactive `llms.txt` integration
    *   **Evidence:** `/public/llms.txt` correctly outlines services, technologies, and URLs.
    *   **Impact:** ✅ **Pass**. Excellent work. This properly feeds AI summary engines like Perplexity, SearchGPT, and Claude.
